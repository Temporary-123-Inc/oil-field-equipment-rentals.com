# Temporary Kitchen Rental applicability matrix

This rebrand follows the target site's visible offer, not the broader TemporaryKitchenRental source catalogue.

| Visible / promoted | Retained only as legacy context | Removed from navigation, catalogue, and forms |
| --- | --- | --- |
| Mobile kitchen trailers and modular kitchen facilities | Existing public URLs and source routes that are not in the current target navigation | Shower trailers, restroom trailers, combination hygiene trailers, sleeper units, workforce housing, laundry, handwashing, tents, offices, and base-camp packages |
| Dishwashing / warewashing trailers | Historic editorial or authority pages, provided they remain reachable and clearly scoped | Any claim that those excluded units are inventory offered by Temporary Kitchen Rental |
| Refrigeration trailers and refrigerated containers | Location routes, calculator route, contact route, and core target aliases |  |

The visible taxonomy and quote form use only the three promoted families. Every rendered route must retain exactly one primary H1 that matches its actual kitchen, dishwashing, refrigeration, location, or planning subject. No legacy URL is deleted or redirected by this matrix.
