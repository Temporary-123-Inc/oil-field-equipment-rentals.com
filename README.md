# Temporary Kitchen Rental website rebuild

Rebuild of [oil-field-equipment-rentals.com](https://oil-field-equipment-rentals.com/) using the approved Oil Field Equipment Rentals layout system while preserving the source site's product paths, contact paths, and state/city URL structure.

## Local development

```sh
pnpm install
pnpm dev
```

## Verification

```sh
pnpm typecheck
pnpm build
```

Preview builds are intentionally marked `noindex`. The production domain is not connected by this repository or its preview deployment.
